# LiftedSpectra
Python scripts and Mathematica files for Robichon, Monthus, Krauth: arXiv:2609.05183

## Content of this repository

Mathematica notebook (and .pdf mirror):

  * RLamLGreen.nb (Representation of diagonalizable matrices, Green's matrix)
  * RLamLGreen.pdf (mirror of the above)

Python scripts in the directories:  

  * Figure_1_Flat  
  * Figure_2_ReversibleNonReversible  
  * Figure_4_Lifted_Square  
  * Figure_5_Lifted_Wedge  
  * Figure_6_Lifted_V

The programs reproduce the figures 1,2,4,5,6. Furthermore, they allow one to test a number of analytic results for Kemeny times agains numerical diagonalizations.
